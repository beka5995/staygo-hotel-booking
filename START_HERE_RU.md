# Как открыть StayGo

1. Распакуй архив в новую папку. В Android Studio нажми Open и выбери **StayGo** — внутри должен быть `pubspec.yaml`.
2. Открой Terminal внизу Android Studio.
3. Для сайта в Chrome напиши:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_web.ps1
```

Скрипт сам выполнит `flutter pub get`, запустит сервер запросов и откроет Chrome. Терминал оставь открытым. Интернет нужен. Первый запуск Flutter может занять несколько минут.

Для эмулятора Android:

```powershell
flutter pub get
flutter run
```

Если `flutter` не найден, проверь путь к Flutter SDK в настройках Android Studio и PATH. Нужен Dart не ниже 3.13.2 — такой SDK указан в исходном проекте.

## Что показать преподавателю

- Explore: сначала загрузка, затем реальные отели. Открой город и переключи List/Grid.
- Потяни вниз именно область карточек. Будет повторный запрос и новый доступный отель сверху. Есть и кнопка обновления.
- В List свайпни карточку влево → UNDO. Удали все видимые карточки → Reset Catalog.
- Открой отель: фото, закладка, рейтинг, цена при наличии, галерея, Share, кнопка Back to hotels.
- Добавь отель в Trip List, открой значок чемодана, измени ночи, удали отель и вернись — каталог сразу обновит кнопку.
- Favorites и Profile: регистрация с проверкой полей, пароля, условий и роли.
- Включи авиарежим на устройстве, где запущено приложение. Подожди примерно 12 секунд: Explore очистит каталог и покажет Retry Connection. Включи интернет и нажми Retry. Если выключил интернет на ноутбуке, а приложение работает в другом телефоне, отключи сеть на самом телефоне.

**Как объяснить связь с интернетом:** «Приложение делает HTTP GET к каталогу отелей, получает JSON и преобразует его в объекты Hotel. Пока ждёт ответ — показывает загрузку. Если запрос не удался — показывает ошибку и Retry. Retry повторяет запрос. Для цены выполняется отдельный запрос тарифов. В браузере запросы идут через небольшой сервер из проекта, потому что источник ограничивает прямой доступ из браузера».

Цены в USD: примерный тариф на одну ночь через 14 дней. Если источник не дал цену, написано Price on request; этот отель не добавляет выдуманную сумму к итогу. Trip List — план поездки, а не оплаченное бронирование. Галерея различает фото отеля и Travel inspiration. Главный баннер создан ИИ.
