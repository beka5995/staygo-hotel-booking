# LAB 11 — заметки и настройки

В этом же приложении добавлен экран **Notes**, открываемый значком заметок справа сверху рядом с корзиной. Каталог, детали, избранное, регистрация и корзина/список поездки сохранены. Notes работает без интернета; каталог продолжает использовать сеть по LAB 10.

## Где смотреть

- `lib/main.dart`: `WidgetsFlutterBinding.ensureInitialized()` → `await PreferencesStore.load()` → `runApp(...)`. Сохранённая тема известна до первого кадра Flutter.
- `lib/theme/app_theme.dart`: светлая и тёмная темы. `MaterialApp.themeMode` обновляется через общий PreferencesStore.
- `lib/state/preferences_store.dart`: `getBool`, `getString`, `setBool`, `setString`, значения по умолчанию, очередь записи.
- `lib/models/note_item.dart`: `id`, `title`, `dateText`, `isCompleted`, `toJson()` и `fromJson()`.
- `lib/screens/notes_screen.dart`: имя + Save name, Dark mode, добавление заметки сверху, checkbox, удаление.
- `test/preferences_store_test.dart` и `test/notes_widget_test.dart`: сохранение и восстановление, быстрые изменения, JSON и размеры экранов.

## Ключи SharedPreferences

| Ключ | Тип | Назначение |
| --- | --- | --- |
| `app_theme_dark_mode` | bool | Тема; по умолчанию false |
| `user_display_name` | String | Отображаемое имя; по умолчанию Guest User |
| `user_notes_json` | String | JSON-массив заметок |
| `saved_favorites_json` | String | JSON-массив избранных товаров/отелей |
| `saved_cart_json` | String | JSON-массив корзины / Trip List с выбранными параметрами |

Имя на этом экране — локальное отображаемое имя. Оно не меняет email, пароль и имя аккаунта в существующей SQLite-регистрации. Пароли и токены в SharedPreferences не записываются.

При изменении списка вызываются `toJson()` → `jsonEncode()` → `setString()`. При запуске: `getString()` → `jsonDecode()` → `NoteItem.fromJson()`. Новое состояние показывается после подтверждения записи плагином. Ошибки сохранения видны на экране. Повреждённый JSON не должен уронить приложение; исходная строка не переписывается при чтении.

## Как проверить настоящий Cold Restart

1. Запусти приложение на телефоне или эмуляторе.
2. Открой Notes. Введи своё имя и нажми **Save name**.
3. Добавь **две заметки**, одну отметь выполненной.
4. Включи **Dark mode**. Дождись окончания сохранения — переключатель и кнопки снова станут активными.
5. Полностью заверши процесс приложения. На Android надёжнее использовать **Настройки → Приложения → приложение → Остановить**; не нажимай очистку данных. На iOS смахни приложение из переключателя.
6. Запусти приложение заново через его иконку. Тёмная тема должна примениться сразу к первому кадру Flutter. Имя покажется в заголовке, а две заметки и checkbox восстановятся на экране Notes.
7. Удали одну заметку и повтори перезапуск: она не должна вернуться. Выключи Dark mode и проверь, что светлая тема тоже сохраняется.

**Hot reload и hot restart не заменяют force-kill тест.** Автотесты моделируют новое приложение и новый кэш настроек, но не являются проверкой завершения процесса на реальном устройстве. Этот этап нужно показать преподавателю на своём телефоне/эмуляторе.

## Для Chrome

Запускай `powershell -ExecutionPolicy Bypass -File .\run_web.ps1`. У каждого проекта фиксированный отдельный порт, чтобы веб-хранилище сохранялось между запусками и не смешивалось с другим проектом. Используй обычное окно браузера, один и тот же адрес и профиль, не очищай данные сайта. Закрытие окна и повторное открытие проверяет веб-вариант сохранения; для основной защиты используй телефон/эмулятор, как указано в задании.

## Короткая защита

«Я сохраняю тему и отображаемое имя в SharedPreferences как bool и String. Заметки — это объекты NoteItem; я превращаю их в JSON-массив и сохраняю одной строкой. При запуске читаю настройки до runApp, поэтому первый кадр сразу использует нужную тему. При добавлении, checkbox и удалении сразу обновляю сохранённый JSON. После полного завершения процесса данные восстанавливаются с устройства».

**Вопрос: почему нельзя хранить пароль в SharedPreferences?** Это обычное хранилище настроек, не предназначенное для секретов. Для токенов и других секретов используют защищённое хранилище, опирающееся на Keychain/Keystore. В существующем локальном учебном аккаунте используется bcrypt-хеширование в SQLite; это не превращает SharedPreferences в безопасное хранилище паролей.

## Дополнение: избранное и корзина

Избранное и корзина / Trip List теперь автоматически сохраняются через `PreferencesStore.saveItems()` и восстанавливаются через `readItems()` до отображения основного экрана. Модели используют `toSavedJson()` / `fromSavedJson()`. Сохраняются размер и количество кроссовок либо число ночей отеля. Последовательная очередь записи сохраняет порядок быстрых изменений. Повреждённые записи пропускаются при чтении.

Проверка: добавь избранное и позицию в корзину, измени параметры, полностью останови приложение и открой снова. Затем удали выбранное и повтори перезапуск: удалённое не должно вернуться. Это локальные данные установки приложения, не синхронизация между устройствами или отдельными аккаунтами. Каталог по-прежнему запрашивается из интернета; восстановленные выбранные позиции не заменяют каталог. Фотографии по сетевым URL могут быть недоступны без сети.

В нижнем меню осталось три раздела. Notes открывается кнопкой справа сверху рядом с корзиной; стрелка назад возвращает на прежний раздел.

Карточки отелей появляются после ответа каталога. Тарифы загружаются отдельно параллельно; до ответа показано Checking price…. Ошибка тарифа не скрывает отели, а показывает Price on request. Новая цена обновляется и в открытых деталях. Запоздавший ответ не возвращает удалённый отель и не заменяет новый каталог старым.
