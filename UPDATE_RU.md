# Обновление LAB 11

Если уже пользуешься предыдущей версией, останови приложение клавишей q в его терминале. Распакуй ZIP отдельно и скопируй содержимое папки проекта в свою прежнюю папку проекта с заменой файлов. Сохрани существующие `.dart_tool` и `.git`; не выполняй flutter clean и не очищай данные браузера. Так сохраняется отладочный профиль Chrome. При запуске из новой папки прежние веб-данные могут не перенестись.

В терминале прежней папки проекта:

```powershell
flutter pub get
powershell -ExecutionPolicy Bypass -File .\run_web.ps1
```

На телефоне/эмуляторе не удаляй приложение и не очищай его данные; запускай обновление через flutter run. Ключи существующих заметок, имени и темы не изменены. Сохранение корзины и избранного начинается с этой версии; закрытые в старой версии несохранённые позиции восстановить нельзя.

Для чистой установки достаточно распаковать ZIP и открыть папку с pubspec.yaml. Основные шаги защиты описаны в LAB11_RU.md.
