# Обновление приложения

Для чистой установки распакуй ZIP и открой папку с `pubspec.yaml`.

Если обновляешь существующую папку:

1. Останови приложение клавишей `q` и закрой окно Chrome, открытое Flutter.
2. Переименуй прежнюю папку проекта и оставь её как резервную копию.
3. Распакуй новую версию. Помести папку проекта по тому же пути, по которому лежала прежняя.
4. Скопируй `.git` из резервной копии, если хочешь сохранить историю Git. Для сохранения данных из отладочного Chrome скопируй также `.dart_tool`. Используй прежний веб-адрес, не выполняй `flutter clean` и не очищай данные браузера.

В терминале новой папки выполни:

```powershell
flutter pub get
powershell -ExecutionPolicy Bypass -File .\run_web.ps1
```

Для Android или iOS запусти `flutter run`. Чтобы сохранить данные на устройстве, установи обновление поверх приложения.
